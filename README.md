# Esprit & Vie

Crée un site web moderne, élégant, responsive et profondément spirituel pour notre groupe de prière catholique.

1. IDENTITÉ DU SITE

Nom :
RENOUVEAU CHARISMATIQUE CATHOLIQUE
Groupe de Prière de Zoundja

Le site représente une communauté chrétienne catholique et doit transmettre :

la foi ;

la prière ;

la joie ;

l'espérance ;

la fraternité ;

l'action de l'Esprit Saint ;

l'évangélisation.

Le site doit être chaleureux et humain, et non ressembler à un site institutionnel froid.

2. OBJECTIF

Le site doit permettre aux visiteurs de :

découvrir le groupe ;

comprendre notre mission ;

connaître nos activités ;

consulter les prochains événements ;

voir les photos des rencontres ;

consulter des prières et ressources spirituelles ;

lire les actualités ;

découvrir les témoignages ;

nous contacter ;

rejoindre facilement le groupe.

Il doit également permettre aux responsables du groupe de gérer facilement le contenu depuis un espace administrateur, sans modifier le code.

3. DESIGN

Créer une identité visuelle chrétienne moderne et élégante.

Palette principale :

blanc / ivoire ;

bleu profond ;

doré élégant ;

touches très discrètes de violet.

Éviter les couleurs trop criardes.

Le design doit être :

lumineux ;

moderne ;

sobre ;

spirituel ;

chaleureux ;

premium ;

parfaitement lisible sur téléphone.

Utiliser de belles images représentant la prière, la communauté, la lumière, l'église, l'adoration et la fraternité chrétienne.

Ne pas utiliser d'images artificielles trop évidentes ou kitsch.

Ajouter des animations très légères :

apparition progressive ;

transitions douces ;

parallaxe légère si pertinent ;

hover subtil.

Ne pas surcharger la page avec des animations.

4. PAGE D'ACCUEIL

Créer une grande section Hero.

Afficher :

"RENOUVEAU CHARISMATIQUE CATHOLIQUE"

"Groupe de Prière de Zoundja"

Phrase principale :

"Unis dans la prière, renouvelés dans l'Esprit."

Texte :

"Une communauté de foi, de prière et de fraternité, rassemblée pour accueillir la présence de Dieu et annoncer l'Évangile."

Boutons :

"Découvrir notre groupe"

"Nos prochaines activités"

Ajouter une belle image ou vidéo en arrière-plan avec un overlay sombre très léger pour assurer la lisibilité.

5. SECTION — BIENVENUE

Titre :

"Bienvenue dans notre communauté"

Présenter brièvement le groupe et son objectif.

Le texte doit être chaleureux et accessible.

Ajouter une image représentant une communauté chrétienne en prière.

6. SECTION — NOTRE MISSION

Créer trois ou quatre cartes :

PRIÈRE
"Nous nous réunissons pour prier, louer Dieu et rechercher sa présence."

FRATERNITÉ
"Nous grandissons ensemble dans la foi, l'amour et la communion fraternelle."

ÉVANGÉLISATION
"Nous annonçons l'Évangile et témoignons de l'amour du Christ."

FORMATION
"Nous approfondissons notre foi à travers les enseignements et la formation chrétienne."

7. SECTION — NOS ACTIVITÉS

Créer une section dynamique présentant :

Groupe de prière

Chapelet

Adoration

Louange

Enseignements

Évangélisation

Formation

Rencontres des jeunes

Retraites

Événements diocésains

Chaque activité doit pouvoir être gérée depuis l'administration.

8. AGENDA / ÉVÉNEMENTS

Créer une page "Agenda".

Afficher les événements sous forme de cartes.

Chaque événement doit avoir :

titre ;

date ;

heure ;

lieu ;

description ;

image ;

catégorie ;

bouton "En savoir plus".

Prévoir une page détaillée pour chaque événement.

Prévoir également un bouton :

"Je souhaite participer"

qui peut rediriger vers WhatsApp.

9. ACTUALITÉS

Créer une page "Actualités".

Les responsables doivent pouvoir publier :

annonces ;

comptes rendus ;

informations importantes ;

événements ;

nouvelles du groupe.

Chaque article doit avoir :

titre ;

image ;

date ;

auteur ;

catégorie ;

contenu ;

partage WhatsApp ;

partage Facebook.

10. GALERIE

Créer une belle galerie photos.

Organiser les photos par événement.

Exemples :

Rencontres de prière

Formations

Camps

Évangélisation

Jeunesse

Célébrations

Vie fraternelle

Ajouter une visionneuse plein écran lorsqu'on clique sur une photo.

Prévoir l'ajout et la suppression des photos depuis l'administration.

11. RESSOURCES SPIRITUELLES

Créer une page "Ressources".

Catégories :

Prières

Enseignements

E-books

Documents PDF

Audios

Vidéos

Lectures spirituelles

Les administrateurs doivent pouvoir ajouter facilement une ressource.

Pour les PDF, permettre :

téléchargement ;

consultation lorsque possible ;

titre ;

description ;

catégorie ;

date.

12. TÉMOIGNAGES

Créer une section "Témoignages".

Afficher des témoignages de membres avec :

prénom ;

éventuellement photo ;

témoignage ;

date.

Prévoir une validation par l'administrateur avant publication.

13. PAGE "QUI SOMMES-NOUS ?"

Créer une page complète présentant :

notre histoire ;

notre mission ;

notre vision ;

notre spiritualité ;

nos valeurs ;

notre communauté.

Ajouter une chronologie si cela est pertinent.

14. CONTACT

Créer une page "Contact".

Afficher :

téléphone ;

WhatsApp ;

adresse/localisation ;

horaires des rencontres ;

réseaux sociaux.

Créer également un formulaire :

Nom
Email
Téléphone
Message

Ajouter un bouton WhatsApp très visible.

15. LOCALISATION

Ajouter une section permettant de localiser le groupe de prière de Zoundja.

Prévoir une carte interactive lorsque les coordonnées exactes seront fournies.

Ne pas inventer l'adresse ou les coordonnées GPS.

16. WHATSAPP

WhatsApp doit être très présent dans le site.

Ajouter un bouton flottant :

"Nous contacter sur WhatsApp"

Le numéro doit être facilement modifiable depuis l'administration.

17. ESPACE ADMINISTRATION

Créer un véritable tableau de bord /admin.

L'administration doit permettre de gérer sans coder :

événements ;

activités ;

actualités ;

photos ;

albums ;

ressources ;

témoignages ;

informations du groupe ;

coordonnées ;

liens sociaux ;

contenu de la page d'accueil.

Dashboard avec statistiques :

nombre d'événements ;

nombre d'articles ;

nombre de photos ;

nombre de ressources ;

nombre de témoignages.

Créer une interface simple, claire et adaptée à des personnes qui ne sont pas développeurs.

18. AUTHENTIFICATION

Créer une authentification sécurisée pour les administrateurs.

Les visiteurs ne doivent jamais accéder au dashboard.

Prévoir des rôles si nécessaire :

Administrateur

Éditeur

L'administrateur peut tout gérer.

L'éditeur peut gérer les contenus mais pas les paramètres sensibles.

19. BASE DE DONNÉES

Utiliser une architecture propre et évolutive.

Prévoir des tables/collections pour :

users ;

events ;

activities ;

posts ;

albums ;

photos ;

resources ;

testimonials ;

site_settings.

Les contenus doivent être séparés du code afin que le site puisse évoluer facilement.

20. RESPONSIVE

Le site doit être parfaitement responsive :

téléphone ;

tablette ;

ordinateur.

Priorité absolue à l'expérience mobile.

Le menu mobile doit être très propre.

21. SEO

Préparer le site pour Google.

Ajouter :

titres SEO ;

descriptions ;

Open Graph ;

favicon ;

URLs propres ;

sitemap ;

données structurées lorsque pertinent.

Nom du site :

"Renouveau Charismatique Catholique — Groupe de Prière de Zoundja"

22. PERFORMANCE

Le site doit être rapide.

Optimiser :

images ;

chargement ;

composants ;

animations.

Ne pas charger inutilement de grosses ressources.

Menu principal :

ACCUEIL

AGENDA

"NOUS REJOINDRE"

24. FOOTER

Créer un footer élégant avec :

Groupe de Prière de Zoundja

Mention :

"© 2026 Renouveau Charismatique Catholique — Groupe de Prière de Zoundja. Tous droits réservés."

25. IMPORTANT — CONTENU

Ne pas inventer :

numéro de téléphone ;

adresse ;

coordonnées GPS ;

horaires ;

noms des responsables ;

dates d'événements ;

liens sociaux.

Lorsque ces informations sont inconnues, créer des champs facilement modifiables dans l'administration ou utiliser temporairement un texte du type :

"Informations à venir".

26. TECHNOLOGIE

Utiliser une architecture moderne, propre et maintenable.

Privilégier :

React ;

TypeScript ;

Tailwind CSS ;

composants réutilisables ;

Supabase si une base de données et une authentification sont nécessaires.

Le code doit être propre et organisé.

27. IMPORTANT POUR LOVABLE

Ne crée pas simplement une landing page.

Je veux un véritable site communautaire évolutif avec :

SITE PUBLIC
+
ESPACE ADMINISTRATION
+
BASE DE DONNÉES
+
AUTHENTIFICATION
+
GESTION DES CONTENUS.

Commencer par construire une première version complète et fonctionnelle avec toutes les pages principales et l'architecture d'administration.

L'interface doit être en français.

Le résultat doit donner l'impression d'un véritable site officiel d'une communauté chrétienne catholique moderne, accueillante et active.
